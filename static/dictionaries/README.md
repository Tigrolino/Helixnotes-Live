# Dictionaries

`en.txt` - English wordlist used by the offline spelling-correction feature
(`src/lib/editor/spellcheck.ts`). One lowercase word per line, ~370k entries.

Source: https://github.com/dwyl/english-words (`words_alpha.txt`), itself built from
public-domain wordlists (infochimps.com and others). Released into the public domain
under the Unlicense - see that repo's `LICENSE.md`. No attribution required, but credited
here for provenance.
